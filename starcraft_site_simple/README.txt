Простой сайт о StarCraft.

1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Все страницы связаны меню.
4. Для публикации загрузите все файлы на GitHub и включите Settings → Pages → Deploy from a branch → main → /(root).

Не удаляйте папки images и files, иначе картинки и ссылки не будут работать.
